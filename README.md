# Yarragunta Charan Kumar Reddy — Standalone Portfolio

A self-contained, plain HTML/CSS/JS version of the personal portfolio for **Yarragunta Charan Kumar Reddy**, an Automotive Embedded System Engineer and Automotive Testing Engineer.

This package does not require Lovable, React, or any build tooling. It can be opened directly in a browser or hosted on any static web server.

## What is included

- `index.html` — complete one-page portfolio
- `assets/css/styles.css` — compiled styles (Tailwind CSS-based custom theme)
- `assets/js/main.js` — vanilla JavaScript for typing animation, counters, scroll reveals, mobile menu, and contact form validation
- `assets/images/` — profile and project images
- `assets/files/resume.pdf` — downloadable resume

## How to view

### Option 1: Open directly
Double-click `index.html` to open it in your browser.

### Option 2: Use a local server (recommended for exact font/image loading)
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## How to host

Upload the entire folder to any static hosting service such as:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- Any web server
